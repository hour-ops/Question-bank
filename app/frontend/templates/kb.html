怎么用这个知识库（特色功能）
  • 检索要“具体”：搜「RAG 的重排序」比搜「关系」准得多——切块按考纲小节做， 命中后显示「章 › 节 › 小节」路径，点开就是该知识点的完整上下文。
  • 回答只依据命中块：生题 / 判分调用大模型时，把检索到的块作为唯一依据喂进去； 命中块里没有的内容不补、不编（宁可不答）。
  • 返回 0 块 = 确实没收录，不是“没搜到”：先去「设置 → 知识库」把对应教材/资料入库，再问。
  • 填了 API Key 之后：可在题目页对当前题提问，系统先检索本库再回答，并标出引用的「章 › 节」， 方便回原文核对——这就是“不会出现幻觉”的用法。
