二、名词解释

1.操作系统:操作系统是计算机系统中非常重要的系统软件，其功能是管理和控制计算机软件和硬件资源，使计算机各部分协调工作;合理组织计算机工作流程，为用户使用计算机提供友好的人机界面，方便用户使用计算机系统。

2.进程管理:处理机(CPU)是计算机中最宝贵的硬件资源，程序只有获得CPU才能运行进程管理主要对处理机进行分配和管理。在计算机系统中，以进程为基本单位分配和使用处理机，因此对处理机的管理最终归结为对进程的管理。进程管理的主要功能是进程控制、进程调度、进程同步及进程通信。

3.分时操作系统:分时操作系统的工作方式是一台主机连接了若干个终端，每个终端有一个用户在使用。用户交互式地向系统提出命令请求，系统接收每个用户的命令，采用时间片轮转方式处理服务请求，并通过交互方式在终端上向用户显示结果。

4.桌面:桌面是 Windows 操作系统和用户之间的桥梁，几乎 Windows 中的所有操作都是在桌面上完成的。Windows 10 的桌面主要由桌面背景、桌面图标、任务栏等部分组成。

5.任务栏:默认情况下，任务栏位于桌面的底端，由“开始“按钮、应用程序区域、通知区域、操作中心、显示桌面按钮等部分组成。任务栏的主要作用是显示当前运行的任务、进行任务切换等。

6.对话框:对话框是人机交互的一种重要手段，当系统需要进一步的信息才能继续运行时就会打开对话框，让用户输入信息或做出选择。

7.快捷方式:快捷方式是 Windows 提供的一种快速启动程序、打开文件或文件夹的方法。快捷方式实际上是一种特殊的文件，仅占用 4KB的空间。它不是这个对象本身，而是指向这个对象的指针。

8.资源管理器:资源管理器是 Windows 系统的重要组件，利用"资源管理器"可完成创建文件夹、查找、复制、删除、重命名、移动文件或文件夹等文件管理工作。

9.库:库是 Windows 10 操作系统的一种文件管理模式。库能够快速地组织、查看、管理存在于多个位置的内容，甚至可以像在本地一样管理远程的文件夹。

10.任务管理器:任务管理器提供了有关计算机性能的信息，并显示了计算机上所运行的程序和进程的详细信息。是维护计算机的主要手段之一。


三、简答题

1.简述操作系统的五大管理功能。

操作系统的功能包括进程管理、作业管理、存储管理、设备管理和文件管理五个主要部分。

进程管理:主要对处理机进行分配和管理。

作业管理:是为了合理组织工作流程，对作业进行控制和管理。

存储管理:是指对内存资源进行管理，主要任务是为多道程序运行提供良好的环境。

设备管理:是指对计算机外部设备进行分配、控制和管理。

文件管理:主要负责软件资源管理，包括文件存储空间管理、目录管理、文件存取控制、文件共享与保护。

2.简述退出 Windows 10 的几种方式及其区别(至少三种)。

关机:关闭操作系统并断开主机电源。

重启:计算机在不断电的情况下重新启动操作系统。

睡眠:自动将打开的文档和程序保存在内存中并关闭所有不必要的功能。只需几秒便可恢复，耗电量少。

注销:退出当前账户，关闭打开的所有程序，但计算机不会关闭。可以清空当前用户的缓存空间和注册表等信息。

切换用户:在各用户之间进行切换而不影响每个账户正在使用的程序。

3.简述在 Windows 10 中创建新文件夹的几种方法。

方法1:首先选择目标位置，然后单击快速访问工具栏上的"新建文件夹“按钮，最后命名文件夹。

方法2:首先选择目标位置，然后右击右窗格空白处，在弹出的快捷菜单中选择“新建"一"文件夹"选项，最后命名文件夹。

方法3:首先选择目标位置，然后选择"主页“选项卡，单击"新建文件夹"按钮，最后命名文件夹。

4.简述文件与文件夹的复制和移动操作的区别及常用方法(至少三种)。

区别:复制操作保留了原文件(文件夹)，即系统中存在两份相同的文件。移动最主要的特点是唯一性，即移动过后，原文件夹中不存在该文件了。

常用方法:

1.右击源对象，在弹出的快捷菜单中选择"复制"或"剪切"命令，然后打开目标文件夹,右击右窗格空白处，在弹出的快捷菜单中选择“粘贴"命令。

2.首先选择源对象，选择"主页"一"复制"或"剪切"命令，然后打开目标文件夹，选择“主页"一“粘贴"命令。

3.首先选择源对象，选择"主页"一"复制到"或"移动到"命令菜单中的常用保存位置或单击“选择位置"按钮，选择目标文件夹。

5.简述使用 Windows 10 任务管理器可以完成的主要操作。

任务管理器的主要功能包括:

终止程序、进程或服务:在“进程“或"详细信息"选项卡中选择对应项目，单击“结束任务“按钮;或在“服务"选项卡中右击服务，选择开始、停止或打开服务。

整理自启动程序:在“启动“选项卡中选择启动项，单击“禁用“按钮，可取消该项目的自动启动。

查看计算机性能信息及运行的程序和进程的详细信息。


四、论述题

1.论述 Windows 10 操作系统中“文件"与“文件夹"的基本概念，并结合"资源管理器"说明如何对它们进行有效的分类、存储和管理，以提高工作效率。

·基本概念:

文件:是存储在磁盘上的一组相关信息的集合，可以是程序、文档、图片、声音等。文件名由主文件名和扩展名组成。

"文件夹:是用于存放文件或其他文件夹的容器，用于分类和组织文件。Windows10系统采取树形结构对文件进行分层管理

"有效管理方法(结合资源管理器):

利用树形结构:在资源管理器的导航窗格中，利用树形目录结构清晰地对文件夹进行分级管理，将不同类型的文件放入不同的文件夹中。

使用库功能:将分散在不同位置(如不同磁盘分区、移动硬盘)的同类文件夹(如“文档""图片")添加到同一个"库"中，实现统一管理和快速访问，无需关心文件的具体物理位宣。

规范命名与排序:为文件和文件夹起一个见名知意的名称。利用资源管理器"查看"选项卡中的“排序方式"功能(如按名称、日期、类型、大小排序)，可以快速定位文件。善用搜索功能:在资源管理器的搜索栏中输入关键字或使用通配符(*、?)，可以快速在当前位置及其子目录中查找文件。通过"搜索工具"选项卡还可以进行更高级的条件筛选。文件属性管理:通过右键菜单的“属性“选项，可以设置文件的“只读““隐藏“"存档"等属性,对重要文件进行保护。

创建快捷方式:为最常用的文件夹或文件在桌面或快速访问区域创建快捷方式，实现一键直达。

定期整理:使用“磁盘清理"工具清除无用文件，使用"磁盘碎片整理"优化磁盘性能，保持系

统高效运行。

2.请描述在 Windows 10操作系统中，如何完成以下操作流程(要求说明具体步骤):(操作步骤):。

1.创建“学习资料“文件夹:双击桌面“此电脑"图标打开资源管理器→在左侧导航窗格点击“本地磁盘(D:)"→在右侧工作区空白处右击 一 选择“新建"→"文件夹"→输入文件夹名称“学习资料“后按回车。

2.创建"计划.txt"文档:双击打开刚创建的"学习资料"文件夹一在文件夹内空白处右击一选择“新建“ 一“文本文档”→输入文件名称“计划.txt“后按回车。

3.设置文件属性:右击“计划.txt"文件 一选择"属性"一在弹出的属性对话框中，勾选“只读和“隐藏“复选框 → 点击“确定"。

4.创建桌面快捷方式:在资源管理器中，右键拖动"学习资料“文件夹到桌面空白处 → 松开鼠标 一在弹出的菜单中选择"在当前位置创建快捷方式"。(或右击文件夹，选择"发送到“一"桌面快捷方式”)。

5.压缩文件夹:右击“学习资料"文件夹一选择"添加到压缩文件."→在弹出的对话框中,将压缩文件名改为“资料备份.rar"→ 点击“确定“开始压缩。
