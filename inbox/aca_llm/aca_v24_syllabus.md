## 1. 认证定位

面向企业 AI 通识教育，适合**非技术背景人员**、无算法背景的技术人员，以及希望系统了解大模型应用方法的学习者。
考核重点：大模型基础知识、典型应用方式、AI Agent 使用方法、安全合规要求，以及把大模型能力应用到实际业务场景的能力。

## 4. 六大模块官方描述（原文要点）

| 模块 | 官方描述要点 |
|---|---|
| **1 大模型概念** | 理解大模型是什么、能做什么、**不能直接替人决定什么**；基于上下文生成内容的基本方式；由此带来的**幻觉、训练数据时间范围、上下文限制**；能力边界判断——何时适合生成/总结/分析，何时需要知识库、工具或**人工确认** |
| **2 提示词工程** | 好答案来自好输入；说明**目标、背景、角色、约束、示例、输出格式、评价标准**；复杂任务先列计划与关键信息、确认后再生成；翻译/改写/总结/分类类任务需补充**受众、目的、术语、不可改写信息** |
| **3 增强大模型应用的能力** | 模型不是什么都靠记忆回答；**查企业资料用 RAG，需要实时数据/确定性计算/业务动作时用工具**；RAG 的**解析、切分、检索、重排序、评测**都会影响答案质量；了解 **MCP** 作用（不要求协议细节） |
| **4 大模型微调** | 微调不是万能按钮；适合**稳定行为、格式、风格、分类能力**，或支持轻量模型部署；基本流程：**定义目标 → 准备样本 → 选择基模 → 控制数据质量 → 评估效果**；选型边界——查知识用 RAG、做动作靠工具、**稳行为才考虑微调** |
| **5 大模型 Agent** | 价值是把"回答问题"推进到"完成任务"；要给 Agent **明确目标、资料来源、工具边界、阶段检查点**；**Skill** 用来固化重复工作方法；**自检清单要具体、可核对、有证据**；**高风险动作必须人工确认** |
| **6 大模型安全合规** | 核心是让 AI 在边界内工作；涵盖**内容安全、数据安全、权限控制、生成内容标识、来源留存、审计追踪、人工复核**；医疗/金融/合同/对外发布等高风险场景下 AI 只能辅助整理与起草，**不能替代最终责任人** |

## 5. 课程结构（备考路径，来源：认证页与课程页）

> 来源：`https://edu.aliyun.com/certification/aca13`（认证页课时列表）与 `https://edu.aliyun.com/course/3139400/`（备考指南页）

**认证流程**：01 课程学习 → 02 实验练习 → 03 模拟自测 → 04 认证考试 → 05 领取证书

**课程章节（认证页，共 11 课时）**
- 第1章 认识大模型（2 课时）：认识大模型 / 大模型的典型应用场景
- 第2章 用好大模型（8 课时）：优化输入提升回答质量 / RAG 增强 / 微调改善垂直领域表现 / 安装桌面 Agent / Agent 接入知识库和工具 / 用 Skill 固化工作方法 / 给 Agent 加自检闭环 / 大模型应用的安全合规
- 第3章 拓展与总结（1 课时）：学习总结

**备考指南课程（课程页 3139400，共 8 课时）**
- 第1章 学习路径（1 课时）
- 第2章 **考点指导（6 课时）**：考点1 大模型概念 / 考点2 提示词工程 / 考点3 增强大模型应用的能力 / 考点4 大模型微调 / 考点5 大模型 Agent / 考点6 安全合规
- 第3章 考前冲刺（1 课时）
