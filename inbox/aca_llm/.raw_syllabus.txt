阿里云大模型工程师 ACA 认证考试大纲
考试背景
阿里云大模型工程师 ACA 认证（Alibaba Cloud Certified Associate - LLM）面向
企业 AI 通识教育，适合非技术背景人员、无算法背景的技术人员，以及希望系统了解
大模型应用方法的学习者。该认证主要考核考生对大模型基础知识、典型应用方式、
AI Agent 使用方法和安全合规要求的理解，以及将大模型能力应用到实际业务场景中
的能力。
通过认证可证明的能力
通过该技术认证可以有效证明该认证人员具备以下能力：
● 了解大模型的基本概念、工作原理和常见应用场景，能够与大模型相关技术人员进
行基本沟通协作。
● 掌握提示词工程、RAG、知识库、工具调用、MCP、微调、Agent 和 Skill 等改进
大模型应用效果的方法。
● 能够使用大模型和个人 AI Agent 辅助完成信息提取、内容生成、资料分析、知识问
答、办公自动化等任务。
● 理解如何围绕业务目标和评测机制打造面向他人的高质量 AI 服务。
● 了解大模型应用，尤其是 Agent 应用中的安全合规风险来源与治理方法。
报名方式

建议掌握的知识
建议考生重点掌握以下知识：
• 大模型的基础概念、技术发展脉络、工作方式和典型应用场景。
• 提示词基础、输入优化方法、采访模式、深度思考模式，以及把任务目标、背
景、约束和验收标准讲清楚的方法。
• RAG、知识库服务和知识问答系统的基本原理与质量改进方法。
• 工具调用、MCP 和个人 AI Agent 接入知识库与工具的方法。

考试内容
本认证不要求考生编写代码，也不考模型训练和协议实现细节。考试重点是理解大模
型能力边界，并能在业务场景中选择合适的方法：优化输入、接入知识库、调用工
具、使用微调、协作 Agent，或保留人工确认。
1. 大模型概念
理解大模型是什么，能做什么，不能直接替人决定什么。理解大模型基于上下
文生成内容的基本方式，以及由此带来的幻觉、训练数据时间范围和上下文限
制。掌握能力边界判断：什么时候适合生成、总结、分析，什么时候需要知识
库、工具或人工确认。

2. 提示词工程
好答案来自好输入。掌握如何说明目标、背景、角色、约束、示例、输出格式
和评价标准。面对复杂任务，先列计划和关键信息，确认后再生成；面对翻
译、改写、总结、分类等任务，补充受众、目的、术语和不可改写信息。
3. 增强大模型应用的能力
模型不是什么都要靠记忆回答。掌握选型：查企业资料用 RAG，需要实时数
据、确定性计算或业务动作时用工具。理解 RAG 的解析、切分、检索、重排
序和评测会影响答案质量；了解 MCP 的作用，不要求掌握协议细节。
4. 大模型微调
微调不是万能按钮。掌握微调适合什么：稳定行为、格式、风格、分类能力，
或支持轻量模型部署。理解微调的基本流程：定义目标、准备样本、选择基
模、控制数据质量、评估效果。能区分：查知识用 RAG，做动作靠工具，稳行
为才考虑微调。
5. 大模型Agent
Agent 的价值是把“回答问题”推进到“完成任务”。掌握如何给 Agent 明
确目标、资料来源、工具边界和阶段检查点。理解 Skill 用来固化重复工作方
法，自检清单要具体、可核对、有证据。高风险动作必须人工确认。
6. 大模型安全合规
安全合规的核心是让 AI 在边界内工作。掌握内容安全、数据安全、权限控
制、生成内容标识、来源留存、审计追踪和人工复核。遇到医疗、金融、合
同、对外发布等高风险场景，AI 可以辅助整理和起草，但不能替代最终责任
人。
